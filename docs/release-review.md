## 수정한 문제

### 버튼과 가독성

- 다크 모드의 일반 탭 규칙이 선택 배경을 덮어 어두운 글자가 어두운 배경에 놓이던 오류를 수정했습니다. 선택·마우스 올림·누름·초점을 각각 확인했습니다.
- 상품 추천의 선택 테두리·가격 글씨, 긴 상품명과 용량의 모바일 줄바꿈을 보완했습니다.
- 320px 입고 화면의 3열 잔류를 1열로 바꾸고, 모바일 월 선택 12개 버튼을 두 줄로 배치해 잘림을 해결했습니다.
- 신규 업무 입력에 눈에 보이는 항목 이름과 오늘 날짜 기본값을 추가했습니다. 수량 오류와 예측 안내도 쉬운 말로 바꿨습니다.

### 사이트 구조

- 상단 트리와 과거 상태를 설명하던 개선 포인트 목록을 제거했습니다.
- 판매·입고·공유 업무·과거 매출을 선택하면 입력 → 기록 → 확인 화면의 순서로 연결 그래프가 바뀝니다. 상자를 누르면 연결 조건·주의 사항과 해당 화면 열기 버튼이 나옵니다.
- 모바일에서 상세 설명으로 화면과 키보드 초점이 함께 이동합니다. 판매 내역은 내역 영역으로, 예측은 예측 탭으로 바로 연결합니다.
- 과거 매출이 대시보드 최근 30일 그래프의 날짜별 보충 자료로 쓰이는 실제 동작을 반영했습니다. 반려동물 선택 조건·원가 확인·분석 새로고침 조건도 명시했습니다.
- 새 그래프 스타일 파일이 배포 결과에서 빠지지 않도록 기존 정적 파일 복사 목록에 포함했습니다.

### 업무 중 실수·실패 방지

- 판매·입고 저장 중 폼을 잠가 연속 클릭과 목록 변경을 막았습니다. 같은 판매를 같은 화면에서 재시도할 때 기존 중복 방지 키를 재사용합니다.
- 입고가 저장된 뒤 조회 갱신만 실패했을 때 저장 성공을 명확히 알리고 중복 등록을 피하도록 안내합니다. 성공 후 현재 매입단가 검색 결과도 다시 그립니다.
- 새 업무 생성 후 담당자 연결만 실패하면 생성된 업무 번호를 유지해 담당자 연결만 재시도합니다. 연결 중복 응답은 해당 업무·담당자 조합을 다시 조회해 확인합니다.
- 업무 상태·댓글 저장 실패 안내, 댓글 초안 보관, 업무 A/B 전환 시 늦은 응답이 다른 업무를 덮지 않도록 보호했습니다. 빈 날짜를 선택하면 이전 업무의 쓰기 화면을 닫습니다.
- 반려동물 이름을 입력했지만 추천 항목을 선택하지 않은 경우, 말없이 미지정 판매로 담기지 않도록 안내합니다.
- 상품·반려동물 추천의 방향키 연속 이동, Escape 닫기, 닫힌 목록의 Enter 오선택을 수정했습니다. 입고 단가·반려동물 구매 이력의 늦은 응답도 선택한 대상과 맞는지 확인합니다.
- 오늘 매출과 이번 달 수익을 현재 날짜·월로 집계하고, 판매 요청에 화면에서 선택한 판매일을 항상 보냅니다. 원가 0원 판매가 포함된 수익 지표에는 확인 안내를 표시합니다.
- 예측 데이터를 받는 도중 탭을 왕복하면 같은 요청을 기다리도록 변경해 화면 멈춤을 막았습니다. 날씨 예보를 받지 못했을 때는 안내와 재시도 버튼을 제공합니다.

## 실제 확인과 범위

- 버튼 7종 × 밝음/어두움 × 일반/올림/누름/초점 = 56개 상태의 브라우저 대비 검사. 최소 대비 4.55:1.
- 관리자 9개 메뉴 × 1440·768·390·320px × 밝음/어두움 = 72개 화면 조합. 발견한 320px 넘침·월 버튼 잘림 수정 후 재확인.
- 연결 그래프 4개 흐름 × 3개 크기 × 2개 테마 = 24개 조합에서 카드 선택·설명·키보드·화면 이동 확인. 390px 글자 크기 2배 시험도 실시했습니다. 이는 브라우저 확대율 시험과 구분합니다.
- 기존 종합 회귀 검수는 관리자·직원 로그인, 메뉴, 매출관리 7개 탭, 초성 검색 후 6개 조회·비교 합계, 판매 목록 계산, 업무 상태·댓글 처리, 로그아웃을 포함합니다.
- 추가 회귀 시험은 판매·입고 중복 클릭, 판매 재시도 키, 입고 저장 후 조회 실패, 업무 담당자 부분 저장 재시도, 업무 A/B 응답 순서와 실패 입력 보관, 검색 방향키, 오늘 카드, 연결 그래프, 느린 예측 중 탭 왕복을 포함합니다. 직접 실행 결과 8개 검사군·그래프 24조합 통과, 예상하지 않은 쓰기 0·브라우저 예외 0입니다.
- 저장·실패·재시도 시험의 REST 쓰기는 브라우저 시험 응답으로 가로챘습니다. 이 재검수로 실제 시험 판매·입고·업무·댓글은 생성하지 않았습니다.
- 기존 DB 스키마·정책·권한 규칙은 수정하지 않았고, SQL 실행·대량 변경·Git push·배포는 하지 않았습니다.
