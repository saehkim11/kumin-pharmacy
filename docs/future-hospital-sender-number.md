# 나중에 할 일: 병원 번호로 문자 보내기 (발송 업체 연동)

작성 2026-11-22 · 상태: **보류(지금은 QR 방식 유지)** · 이 문서는 나중에 진행할 때 출발점을 쉽게 찾기 위한 메모입니다.

## 왜 이 문서가 있나
지금 메시지 발송은 QR을 폰 카메라로 비춰 **폰의 문자 앱**에서 보냅니다. 이 방식은 무료이지만 받는 분께는 **그 폰의 번호(010-…)** 가 발신번호로 표시되고, 병원 번호는 문구 끝의 "문의: 02-543-1945"로만 알립니다. **받는 분께 병원 번호가 발신번호로 표시되게** 하려면 아래 방식이 필요합니다. 사용자는 우선 지금 방식(QR)을 쓰기로 했고(2026-11-22), 이 개발은 나중으로 미뤘습니다.

## 한 줄 요약
문자 발송 업체(솔라피·알리고 등)에 **병원 번호(02-543-1945)를 발신번호로 사전등록**하고, ERP가 서버(Supabase Edge Function)를 통해 업체 API로 문자를 보내면 받는 분께 병원 번호가 표시됩니다. 폰·QR이 필요 없고 "보냈어요" 기록도 자동으로 남습니다.

## 지금 방식으로는 안 되는 이유
- 문자 앱에서 보내는 문자는 항상 그 폰의 번호로 나갑니다. 앱이나 ERP가 발신번호를 바꿀 수 없습니다.
- 인터넷으로 보내는 문자는 **사전에 등록한 발신번호로만** 발송할 수 있게 되어 있어(발신번호 사전등록제) 임의 번호 표시는 막혀 있습니다.

## 진행할 때 할 일
**사장님이(대신할 수 없는 일)**
1. 발송 업체 선택·가입(솔라피, 알리고 등. 소량 요금과 장문(LMS) 단가를 가입 전에 문의).
2. 병원 번호 **발신번호 등록**: 02 유선번호는 지역번호 포함해 등록합니다(050·030 안심번호는 등록 불가). 병원(사업자) 명의로 **통신서비스 이용증명원**(통신사 고객센터에서 발급)과 **사업자등록증**이 필요하고, 신청 후 병원 번호로 ARS 인증 전화가 오며 승인은 보통 최대 1일 걸립니다. 서류와 기간은 업체마다 다를 수 있습니다.
3. API 키 발급. **키는 대화창이나 코드에 붙여넣지 않고** Supabase 비밀 저장소(Edge Function 환경 변수)에만 넣습니다.
4. 2026년 11월 도입된 **문자 전송자격인증제**가 계정·발신번호 등록 개수에 미치는 영향을 업체에 확인합니다.

**개발(Claude)**
1. Supabase Edge Function 하나(예: 문자 보내기): 입력은 받는 번호·문구·반려동물·종류, 관리자만 호출 가능, 업체 API 호출 후 결과 반환.
2. 메시지 발송 화면(`app.js`의 `msg*` 구역)에 **[병원 번호로 보내기]** 버튼 추가. 눌러서 성공하면 이력에 `sent`로 자동 기록(`rpc_log_reminder` 재사용, `kind='manual'`). 실패하면 이유를 쉬운 말로 보여 주고 QR은 그대로 쓸 수 있게 둔다.
3. QR 방식은 **보조로 유지**(업체 준비 전·장애 때 사용). 두 방식 모두 같은 이력(`reminder_log`)에 남는다.
4. DB 변경이 필요하면(예: 발송 결과·업체 메시지 번호 저장) 사용자 승인 후 진행. 보낸 문구에 번호를 저장하지 않는 원칙은 유지한다.

## 연결해 볼 곳(현재 코드)
- 메시지 화면 구현: `app.js`의 `// ---------- 메시지 발송:` 구역(`msgRefreshQr`, `msgRecordSend`, `msgPending`), 문구·번호 가공은 `messaging-core.js`.
- 이력·기록 DB: `db/22_reminder_log_pref.sql`(`reminder_log`, `owner_reminder_pref`, `rpc_log_reminder`).
- 문의 전화번호는 문구 끝에 **기본으로 들어가는 상태**(스위치로 뺄 수 있음). 병원 번호로 발송하게 되면 문구 끝 번호가 필요 없어질 수 있으니 그때 기본값을 다시 정한다.
- 설계 배경: `docs/superpowers/specs/2026-11-22-reminders-design.md` §19~§20.

## 비용(조사 당시 참고, 소량 요금은 미확인)
- 문구가 길어(한글 약 45자 이상) 장문(LMS)으로 나갈 가능성이 높습니다. 조사된 단가는 건당 약 26~45원(부가세 별도)이며 업체·충전액에 따라 다릅니다. 월 100건이면 약 3천~5천 원 수준입니다.
- 알리고 단가는 블로그 기재 값이라 공식 요금표 확인이 필요합니다.

## 법·규정 유의(이미 조사한 내용)
- **재구매 안내 등 광고성 문자**는 업체 발송으로 바꿔도 규정이 그대로 적용됩니다: (광고) 표기, 전송자 명칭·연락처, 수신거부 방법 안내, 오후 9시~오전 8시 전송 별도 동의, 거래 종료 후 6개월 이내 예외. 업체가 **무료 수신거부 번호(080)** 를 제공하면 수신거부 안내가 쉬워질 수 있으니 가입 때 확인합니다.
- 접종·예약·진료 안내는 정보성으로 보는 해석이 일반적입니다(확정은 아님). 자세한 내용은 설계 문서 §12.
